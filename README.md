# 🎙️ Voice Assistant using Python

A simple voice-controlled assistant built with Python that listens to voice commands and automatically opens websites and applications.

## 🚀 Features

* Open YouTube using voice commands
* Open Gmail using voice commands
* Open Google Search
* Launch Windows Calculator
* Continuous voice listening
* Speech-to-text conversion
* Basic error handling

## 🛠️ Technologies Used

* Python 3
* SpeechRecognition
* PyAudio
* Webbrowser
* Subprocess

## 📂 Project Structure

```text
VoiceAssistant/
│
├── voiceassistant.py
├── requirements.txt
└── README.md
```

## 📦 Installation

Install the required dependencies:

```bash
pip install SpeechRecognition pyaudio
```

## ▶️ Running the Project

```bash
python voiceassistant.py
```

## 🎤 Supported Voice Commands

| Command         | Action                   |
| --------------- | ------------------------ |
| Open YouTube    | Opens YouTube            |
| Open Gmail      | Opens Gmail              |
| Open Google     | Opens Google Search      |
| Open Calculator | Opens Windows Calculator |
| Stop            | Exits the application    |

## 💻 Example

```text
Listening...
You said: open youtube
```

The assistant will automatically launch YouTube in your default browser.
